# BMSA FSD — العبها صح

تجربة موبايل خفيفة بالمصري للـ Recruitment Booth في النقابة. **Deal or No Deal: Sponsor Edition** و**Pitch Pong**، ١٨ سيناريو، ٣ قرارات في الجولة، وتغذية راجعة فورية.

تحديات Sponsorship وFundraising وMerchandise وPartnerships. كل العروض والأرقام افتراضية. النتيجة للتعلّم والتعرّف على FSD، وليست تقييم قبول أو وعدًا بمكافأة. علامة B المستخدمة ليست شعار BMSA الرسمي.

## التشغيل محليًا

تحتاج Node.js فقط، بدون تثبيت أي حزم:

```powershell
node serve.cjs
```

افتح `http://127.0.0.1:4173`. أوقف التشغيل بـ Ctrl+C. الاختبارات:

```powershell
node --test tests/core.test.cjs
```

## النشر على GitHub Pages

1. ارفع محتويات المشروع إلى مستودع GitHub عام على فرع `main`.
2. من **Settings → Pages** اختار **Deploy from a branch**.
3. اختار الفرع **main** والفولدر **/docs**، ثم **Save**.
4. انتظر اكتمال **pages build and deployment**، وخُد الرابط الذي يعرضه GitHub. لا تعتمد على عنوان متوقَّع قبل التحقق منه.

كل روابط الأصول نسبية لتعمل على رابط مشروع GitHub Pages. ملف `docs/.nojekyll` يمنع معالجة Jekyll. لا يوجد Build أو Backend أو مفاتيح سرية. كل تعديل تدفعه إلى `docs` يُنشر تلقائيًا وفق إعداد Pages أعلاه.

## إضافة رابط التقديم الرسمي

عدّل `applicationUrl` في `docs/config.js` ثم احفظ التعديل على `main`. استخدم رابط HTTPS رسميًا كاملًا فقط. القيمة حاليًا فارغة؛ زر التقديم يوضح أن الرابط لم يُضف ويطلب سؤال فريق الـ Booth. لا يوجد رابط تقديم افتراضي ولا بيانات يتم جمعها داخل اللعبة.

بعد نجاح التحديث جرّب الزر. لو عنوان اللعبة ثابت، QR لا يحتاج تغييرًا عند إضافة رابط التقديم.

## الخصوصية

كود اللعبة لا يطلب أسماء أو أرقام موبايل أو بريد إلكتروني. لا يوجد تسجيل دخول أو Analytics أو Cookies أو Local Storage أو إرسال إجابات. النتيجة في ذاكرة الصفحة وتتمسح بالرجوع للبداية أو الريفريش. كل الأصول من نفس الموقع، وسياسة الصفحة تمنع إرسال اتصالات شبكة من كود اللعبة.

GitHub Pages يسجّل IP الزائر لأغراض الأمان، حتى لو لم يسجّل الدخول؛ لذلك لا يوجد وعد بانعدام سجلات البنية التحتية. [توضيح GitHub الرسمي](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).

رابط التقديم عند إضافته يفتح موقعًا خارجيًا بسياسة خصوصية مستقلة، ولا يستقبل نتيجة اللعب.

## التشغيل وسط الزحمة

- QR واحد على ورقة أو جهاز المنظم يكفي؛ كل طالب يلعب من موبايله.
- قول: «امسح الكود، اختار لعبة، وخُد ٣ قرارات في حوالي دقيقة».
- في Pitch Pong الضغط على الكوباية يحل محل الرمي؛ لا تحتاج كوبايات أو كور.
- لا تطلب اسمًا أو Screenshot للنتيجة. على موبايل مشترك، اضغط «البداية» بين الطلبة.
- أول فتح أو ريفريش يحتاج إنترنت. الجولة المفتوحة تكمل بعد انقطاعه، بدون ضمان تحميل أوفلاين.
- احتفظ بالهوامش البيضاء للـ QR وجرّب المسح من جهازين على شبكة النقابة قبل البوث.

## المعلومات الناقصة

- رابط التقديم الرسمي لتفعيل الزر.
- الشعار والألوان الرسمية، إن كانت مطابقة الهوية مطلوبة.
